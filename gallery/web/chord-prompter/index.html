Format and connection

| separates bars. Groups after @ assign chord degrees; 1/5 divides one bar. [word] marks each chord's lyric anchor. Edits show in the browser preview as you type, from the same place in the song. Tempo changes apply on the next beat; jumps and strum changes apply on the next bar.

Connect to MIRUI Chord in Chrome or Arc on desktop, or Chrome on Android. Web Bluetooth requires HTTPS or localhost. Unsupported display-font characters are rejected when uploading.

Browser preview uses the shared musical transport.
