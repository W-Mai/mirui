# Site fonts

`geist-latin-wght.woff2` and `geist-mono-latin-wght.woff2` are the Latin subsets of Geist and Geist Mono (variable weight 100–900) from `@fontsource-variable/geist` and `@fontsource-variable/geist-mono` 5.x. Geist is © The Geist Project Authors and licensed under the SIL Open Font License 1.1; see `OFL.txt`.

Chinese text falls back to the platform's CJK face (PingFang SC, Microsoft YaHei, Noto Sans CJK SC).
